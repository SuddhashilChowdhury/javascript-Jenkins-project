Continuous Integration & Deployment

A simple demonstration project using Jenkins Pipeline, Playwright Automation and Netlify Deployment.

Source Control

GitHub stores the application source code and Jenkinsfile.

Automation Testing

Playwright executes automated browser tests before deployment.

CI/CD Pipeline

Jenkins checks out the code, installs dependencies, runs tests and deploys.

Deployment

Netlify hosts the application after successful execution of the pipeline.

Pipeline Flow

  • ✔ Checkout Source Code
  • ✔ Install Dependencies
  • ✔ Execute Playwright Tests
  • ✔ Publish HTML Report
  • ✔ Archive Artifacts
  • ✔ Deploy to Netlify
